# Whisker — Design Document

## Concept

The concept for this new version of Whisker's was how to best improve the game based on the feedback given in COSMOS. This version seeks to add more content to the game, better tutorials, and UI improvements to make Whisker's a funner and more professional experience.

## How to Play

1. You can select start game in the start menu
2. The main game is progressed through various levels. Currently, there are about fifteen levels.
3. Once you complete the story, you will recieve two different endings.

## Characters

- **Player** — a cat baker
- **Customers** — a rabbit, a fox, a dog, a bear, and an old cat granny.
